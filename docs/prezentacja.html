System rezerwacji sal

Aplikacja oparta na ośmiu mikroserwisach Django

PostgreSQL · Docker Compose · Consul · Traefik

Problem i cel

  • Pracownicy rezerwują sale bez konfliktów terminów.
  • Opiekunowie rozpatrują prośby.
  • System wysyła powiadomienia i pokazuje raporty.
  • Każdy obszar działa jako osobna usługa.

Każda usługa z danymi ma własny schemat PostgreSQL.

Spójność i błędy

  • Blokada bazy chroni przed równoczesną rezerwacją jednej sali.
  • Nieudane powiadomienia pozostają w trwałej kolejce do ponowienia.
  • Decyzja jest zapisana przed zmianą statusu; worker ponawia nieudane wywołania.
  • Wywołania usług mają limit czasu i czytelne odpowiedzi błędów.

Demonstracja

  1. Uruchom docker compose up --build -d.
  2. Otwórz portal i Consul.
  3. Dodaj salę i pracownika; przypisz opiekuna.
  4. Utwórz rezerwację, rozpatrz ją i sprawdź powiadomienia.
  5. Uruchom python scripts/smoke_microservices.py.
